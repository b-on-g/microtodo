# Microtodo

Списки задач в духе Microsoft To Do на [$mol](https://github.com/hyoo-ru/mam_mol) и [Гипер Базе](https://github.com/giper-dev/baza). Без регистрации и сервера: данные лежат в браузере и синкаются через узлы Базы.

https://b-on-g.github.io/microtodo/

## Что умеет

- Умные списки: «Мой день», «Важно», «Запланировано», «Задачи».
- Свои списки, переименование, удаление.
- Задача: галка, звезда, шаги, заметка, срок, повтор (день, будни, неделя, месяц, год). Выполненная повторяющаяся задача порождает следующую.
- Завершённые задачи свёрнуты отдельно, поиск по всем спискам.
- «Поделиться»: список переезжает в отдельный шифрованный ленд, владелец раздаёт доступ людям через [$giper_baza_land_rights](https://github.com/giper-dev/baza/tree/master/land/rights). Участник присылает свой публичный ключ из настроек, владелец добавляет его и ставит «Запись», потом шлёт ссылку `#!join=…`, по которой список появляется у участника. Без выданного права ссылка ничего не открывает.

## Свои устройства

Настройки (шестерёнка в меню): установка как приложение и синхронизация. Аккаунт — это ключ Гипер Базы в браузере. На втором устройстве достаточно отсканировать QR камерой или открыть ссылку `#!account=…`: приложение войдёт в тот же аккаунт, а списки, созданные на этом устройстве до входа, перенесутся в него.

## Устройство

- `microtodo.ts` схема: `home` (входящие, свои списки, отметки «Мой день»), `list`, `task`, `step`.
- `app/` книга из меню, страницы списка и карточки задачи.
- `row/`, `details/`, `nav/`, `star/` строка задачи, карточка, пункт меню, звезда.
- `settings/` установка ([$bog_install](https://github.com/b-on-g/install)) и перенос ключа ([$bog_keyqr](https://github.com/b-on-g/keyqr)).
